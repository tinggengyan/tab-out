# Tab Out license worker

This Web-standard Worker exchanges Lemon Squeezy license keys for Tab Out's signed offline entitlement. It contains no browsing data and no checked-in secret.

Required secrets/configuration:

- `ENTITLEMENT_PRIVATE_KEY_JWK`: P-256 private JWK generated by `npm run license:keygen`
- `LEMON_STORE_ID`
- `PRO_VARIANT_ID`
- `SYNC_VARIANT_ID`
- `ALLOWED_ORIGINS`: comma-separated `chrome-extension://<production-id>` origins
- `LEMON_WEBHOOK_SECRET`: signing secret for `POST /webhooks/lemon`
- Optional `LICENSE_STATE` KV binding: stores revocation markers and 30-day deduplication/audit markers without customer or browsing payloads

Deploy `worker.mjs` at `https://license.tabout.app`, set `TAB_OUT_REDEMPTION_URL` to `https://license.tabout.app/redeem`, and put the matching public JWK in `extension/entitlement-config.js`.

The first redemption calls Lemon Squeezy's `/v1/licenses/activate`. Later daily checks call `/v1/licenses/validate` with the saved instance ID. Network failures preserve the last offline entitlement; an explicit invalid/disabled response removes paid feature creation without deleting local data.

Configure Lemon Squeezy to send signed events to `/webhooks/lemon`. `order_refunded` and `subscription_expired` events write a minimal revocation marker when `LICENSE_STATE` is bound, so subsequent redemption is rejected immediately. The raw webhook body and customer fields are never persisted.

Before production, add provider-side rate limiting/WAF rules and retain only coarse request/error counts without license keys or customer data.
