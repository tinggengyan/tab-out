# 打开的标签页与已保存内容

## 升级已有安装

1. 在 Chrome 打开 `chrome://extensions`，找到 Tab Out，点击重新加载。
2. 如果 Chrome 提示新增原生标签组权限，检查后允许；该权限用于保存和恢复组名、颜色、折叠状态。
3. 刷新 Tab Out 页面。首页默认显示“打开的标签页”；“已保存”包含全部原有项目和收纳记录；“浏览记忆”用于找回曾经访问的网页。

不要卸载扩展或清空存储。旧工作区和“标签页组”统一进入项目列表，保留名称、日期与已有窗口布局；迁移前的原始收纳记录会留在本机备份中。重复打开不会产生双份项目。快照和搜索配置会沿用。

首次安装时，开启开发者模式并加载本仓库的 `extension/` 目录；ZIP 包需要先解压再选中扩展目录。

## 保存项目

1. 在“打开的标签页”跨卡片选择要保留的网页，再从统一操作栏保存所选页面。域名和窗口只改变查看方式，不表示项目归属。名称可留空，系统使用页面标题生成名称。
2. 可以新建分组，或添加到已有项目；添加保留原有页面和布局，不以当前选择覆盖旧内容。需要替换时，从保存内容详情进入“替换”，核对将新增、保留和移除的页面。
3. “仅保存”保留页面打开；“保存并收起”会先保存，再关闭预览中明确列出的普通页面。固定标签会保持打开。
4. 点击“已保存”中的名称查看完整链接，可以打开单页或补开尚未打开的页面；已打开页面不会重复创建或移位。移除保存链接只改变保存内容，不关闭浏览器标签；最后一页需通过删除整个分组处理。
5. 取消回到来源视图，保留原选择和滚动位置；完成保存也留在来源，点击结果中的“查看”才进入保存内容。
6. 更多操作中的高级“切换到”需要明确选择来源项目。目标未完整恢复时，来源保持打开；完整成功后才收起已确认的来源页面，共享页和其他项目不受影响。

随手收起和长期整理都保存为项目，不必再区分标签页组、临时收纳或收纳箱。原来的收纳记录拥有相同的继续、更新、重命名、切换与删除恢复操作，最近保存的项目显示在前。基础项目保存不限数量，规则、模板等高级权益不变。稍后查看及其归档仍在独立的次级区域。规则、模板和项目间批量管理可从“高级管理 · 规则与模板”打开。

## 结果与撤销

查看结果中的保存、打开、复用、关闭、保留及失败数量。可点击“查看项目”回到保存结果。部分失败可重试，已经成功的页面不会再次打开。收起后的撤销会优先回到原窗口；原窗口已消失时会创建替代窗口。撤销只恢复页面，已经保存的项目仍保留。

继续项目的失败重试状态保留在当前页面；刷新后继续仍会按已开网址补缺失，但此前原生标签组元数据失败的提示不会持续保留。

恢复的是网址、标签顺序和支持的浏览器元数据，不是网页里尚未保存的表单、内存或任意登录状态。关闭前应保存网页本身的重要编辑。

## 本地备份

项目和布局保存在当前 Chrome 配置中。使用项目页或设置中的导出下载标签与配置备份，界面只记录最近发起导出的时间；这不代表文件已经保管成功或同步到其他设备。普通备份不含浏览记忆正文，记忆须从设置中的独立导出入口另外备份。卸载扩展或迁移电脑前，请保留并核实两类备份文件。导入使用各自入口和预览。

本版本不要求账号或生产付款配置，也未提供跨设备同步。
