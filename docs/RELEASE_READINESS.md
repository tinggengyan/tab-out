## 发布前需要满足的条件

| 项目 | 完成标志 | 当前证据或缺口 |
| --- | --- | --- |
| 保存与继续 | 不强制命名；旧保存内容能找到；部分恢复失败可以重试，原记录仍保留 | 本轮体验收敛范围，结果见任务验收报告 |
| 本地找回 | 基础搜索覆盖打开、已保存和浏览记忆；短词不会因网址片段误匹配；摘要紧凑且能解释命中 | 本轮测试使用合成资料，不代表真实用户的整体找回效果 |
| 数据与配置 | 界面明确区分普通备份和浏览记忆备份；模型配置与数据控制可从设置找到 | 浏览记忆正文在 IndexedDB，普通配置备份不包含该库 |
| 真实模型联调 | 使用用户的兼容服务验证连接、超时、取消、内容授权、引用和费用 | 尚未连接用户实际模型；本地模拟服务不能替代此项 |
| 真实使用观察 | 用户完成保存、继续、找回任务，记录失败原因与耗时 | 用户试用后补充；不凭功能数量推断留存或付费意愿 |
| 隐私联系信息 | 隐私说明填写真实、可用的支持渠道，与商店资料一致 | 当前 PRIVACY.md 保留配置支持邮箱的待办，不编造地址 |
| 收费上线 | 有实际结账、授权签发、撤销/退款处理及完成的销售条款 | 仓库结账地址与签名公钥尚未配置；TERMS.md 含卖方信息待办 |
| 同步 | 完成服务、加密、冲突与恢复验证后再展示可购买计划 | 当前未实现，不以订阅功能对外销售 |

## 交付与试用

本轮任务与实际验证记录位于 [发布前体验收敛](ai-tasks/2026-11-05-release-convergence/task.md)。验收通过的本地试用包也不等于商店审核通过或正式收费上线。

普通备份和浏览记忆备份都可能包含私有网址；浏览记忆备份还可能包含正文。妥善保管导出的文件。界面只在发起下载后提示“已请求导出”，不能把下载请求等同于文件已经保管成功。

本清单不创建定时任务，也不授权推送、上传商店或发布收费服务。
