# 打开与已保存：实现及集成记录

开始2026-11-06，完成验证2026-11-07。数据与界面职责分别见implementation-data.md、implementation-ui.md；本文件记录根实际执行的集成工作。

## 交付行为

- 打开的标签页先选择再保存，跨卡片共用工具栏；取消和完成保留来源，选择栏消失时焦点回可见导航。
- 已保存保留既有项目，名称进入完整详情，可打开单页/补开缺失；管理在更多，支持后台重绘保留菜单及键盘焦点、Escape关闭。
- 已有目标默认追加并保留旧原生布局，显式替换展示新增/保留/移除；移除保存项不关闭浏览器，拒绝移除最后一页。
- 原子提交版本检查防并发覆盖；R1修复来源/切换目标在关闭前变化的边界。四语、固定底栏与独立内容滚动保持。
