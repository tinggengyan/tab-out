# 标签页顶部按钮样式统一

Forge L1：局部、可恢复的视觉修复，不修改操作逻辑或存储。用户反馈标签页三个快捷按钮颜色都不一样。

## 目标与范围

保留“保存并收起”的绿色主操作强调；“保存为项目”和“继续项目”统一为同样的描边次级按钮，使用同一套高度、间距、圆角、边框、文字颜色及交互状态。不以第三套弱化文字样式显示继续项目。悬停及键盘焦点明确。

仅允许修改extension/index.html中tabsSavedBtn的按钮样式类、extension/src/ui/dashboard-navigation.css中标签页快捷按钮的局部样式。保留IDs/action、所有文案、顺序、业务行为和其他页面样式。根负责证据、一次性浏览器核对与新包，不覆盖已有9个ZIP。AGENTS/CLAUDE/JS/权限/存储不动，不操作个人Chrome/提交/发布。

## 通过条件

1. 默认态保存/继续次级按钮的实际背景、文字、边框一致；收起使用已有绿色实心主按钮。
2. hover次级一致且可见变化，主按钮hover保持可读；三按钮focus-visible清晰，无跨页样式影响。
3. en/zh-CN/zh-TW/ja及1440/1366/390宽度不溢出，尺寸和底栏/导航布局保持；语言切换不改操作。
4. 三入口仍分别打开保存预览、当前窗口收起预览和项目列表；取消不保存/关闭，切换视图只在标签页显示本组。
5. 证据显示extension只改HTML/CSS，JS/权限/存储不变；保留原包，另输出试用包。

视觉变化不新增镜像实现的单元测试；使用实际Chrome计算样式、鼠标/键盘交互及截图核对。Developer语法/差异自检；根L1复核并记录验收。
