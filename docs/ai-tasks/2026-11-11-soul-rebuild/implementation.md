## 最终审查与修复

独立审查（Opus）的结论是"修完再合并"。以下问题已全部修复，每条都先写出能复现问题的失败测试，再修到通过：

1. **撤销会把加载中的标签重新打开成空页。** 原因是撤销记录只存了 `url`，没有回退到 `pendingUrl`。
2. **对固定页点"稍后查看"时，撤销按钮指向了上一次操作。** 现在什么都没关掉时，不改动现有的提示条。
3. **双击"关闭全部"后，撤销入口消失。** 现在关闭和收纳操作一次只执行一个，并沿用第 2 条的规则。
4. **收纳某个站点时，记录没有站点名。** 现在用站点名命名。
5. **CI 在浅克隆下必然失败。** 契约测试改为直接写入原版 key 的字面量；工作流去掉了已删除的 `server/`，打包改用 `npm run package`。
6. **恢复和撤销遇到 Chrome 拒绝打开的页面时，这一页会丢失。** 由 Minor 上调为数据丢失问题。现在先打开页面，打不开的页留在收纳记录或"稍后查看"中。

暂缓的 Minor 与不予处理的事项，见交付说明和执行账本。

## 偏离计划之处

每一条偏离都在执行账本中记为 Ruling，最终汇总见交付说明。要点如下：

- 行内 × 关闭这个网址的所有副本，不再只关第一个副本。
- "稍后查看"也纳入撤销范围。
- 去重时优先保留固定页那一份。
- "关闭"按钮改用中性墨色，琥珀色只留给重复项。
- 数量徽标只显示数字。
- 只要有一张卡片放不下完整文案，所有卡片统一改用短文案。
- 右栏用一个 `<aside>` 同时承载"已收纳"和"稍后查看"。
- 英文文案改用 Stash / sites。
- 导入去重同时比较 id 与 sourceId。

## 未做与已知限制

- **页面不会实时刷新。** 与原版一致：在别的窗口开关标签后，需要重新打开新标签页才能看到变化。
- **2.x 的旧数据保留但不再读取。** 包括快照、浏览记忆等。设置里没有"清理旧数据"入口。
- **AGENTS.md 未改。** 这是上游的安装向导，内容仍然适用。
- **CI 不跑真实浏览器测试。** 修改界面后，合并前需要在本地运行 `npm run e2e:home`。
