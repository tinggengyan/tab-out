# 固定底栏与内容滚动实现

状态：开发、集成验证及独立验收完成，冻结 AC1–AC10 全部 PASS（见 acceptance.md）。按 task.md 的用户需求执行。

## 交付行为

页面现在由顶部导航、独立滚动内容和共享底栏三行组成。作者署名及搜索/清理/工作空间/历史/最近删除/设置/升级入口始终位于视窗底部；三视图切换时使用同一底栏及相同坐标。窄屏、多语言换行会增加底栏自身高度，内容区自动缩短，不以悬浮覆盖正文。

三视图保留原控制器和数据。主内容可用滚轮与键盘滚动，保存待办/收纳组随内容滚动。导航保存真实内容容器的位置；切换视图恢复各自位置，刷新仍回到标签页顶部。语言变更在其他控制器重绘前捕获位置，结束后恢复一次；用户主动滚动或切视图会取消待恢复快照。关闭该容器的浏览器自动滚动锚点，避免恢复后二次偏移。

修改源文件：index.html、app.js、src/ui/dashboard-navigation.css/js。导航测试模拟独立 host，禁止以 window 滚动冒充。Chrome 布局/多语言/记忆工具适配真实滚动容器；README、CHANGELOG 已说明行为。详见 core-implementation.md。
