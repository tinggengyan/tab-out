# 固定底栏与独立内容滚动

任务 ID：2026-11-04-fixed-footer；Forge L2。开发前经只读规划确定。

## 原始需求与范围

作者署名及“搜索、清理建议、工作空间、历史现场、最近删除、设置、升级”始终处于视窗底部。切换“标签页、项目、浏览记忆”时底栏齐平，内容区域独立滚动。

现有 footer 已共享，但位于内容流末尾，带 48px 外边距及位移动画。导航和语言切换均记录 window 滚动位置。保留现有 DOM 控制器与用户数据，不新增权限、存储结构或依赖。不改 AGENTS.md、CLAUDE.md、后台、manifest、数据仓库；保留所有先前未提交改动，不提交/推送/发布。

## 方案与归属

- 三视图放入唯一 #dashboardContent 滚动容器；导航及 #dashboardFooter 位于容器外。壳层使用视窗高度三行布局(auto / minmax(0,1fr) / auto)，100vh 回退、100dvh 动态高度。body 不滚动，快捷方式侧栏仍可独立滚动。
- footer 正常占独立一行，自然换行撑高，不覆盖内容；移除旧额外间距和位移动画。内容顶部偏移和保存列 sticky 高度按真实内容区域校正，防止最后内容延伸到底栏后方。
- 导航及语言切换改用内容容器 scrollLeft/scrollTop；保留每视图位置、选择、查询和草稿，刷新仍为标签页顶部。内容容器可获得键盘焦点，并有当前视图的可访问名称。
- 开发者拥有 index.html、style.css、dashboard-navigation.css/js、app.js、导航单元测试；主会话拥有 Chrome 工具、文档、证据及打包。互不覆盖。
