# 统一保存对象为项目

状态：开发前冻结；Forge L3（涉及既有数据、保存/关闭/恢复与多入口兼容）。

## 来源与目标

用户反馈体验者分不清标签页组和项目，提出只保留项目，询问收纳动线。讨论后用户明确采纳方案并要求“开工建设”。

冻结产品方案：一个保存对象、两种保存动作。项目是可命名、可持续更新的一组页面；仅保存保持页面打开，保存并收起在预览确认后先保存再关闭指定普通页面。收纳不再作为独立对象、入口或列表。原 tabGroups 与 workspace 进入同一项目列表/计数/空态，拥有相同的继续、更新、重命名、删除恢复和安全切换能力。名称选填并有可读默认；保存结果可查看项目及撤销收起，撤销不删除项目。

沿用原无限收纳权益：基础项目数量不限；规则/模板/高级历史等现有门控不变。稍后查看、浏览记忆、Chrome 原生标签组布局元数据仍保留；顶层三个导航与固定底栏不变。不新增同步、账号、模型能力或权限，不提交、推送或发布。

## 冻结验收条件

1. 单一对象：仍三个主页视图，无独立标签页组/临时收纳/收纳箱列表；旧新项目统一列表、数量、空态及操作。
2. 旧数据无损：混合旧新记录数量正确；名称/日期/URL/session元数据保留；同URL的不同记录不合并；重复迁移不重复。
3. 故障安全：提交失败保留源、可重试；ID碰撞不覆盖无关项目；多实例初始化/保存不重复或丢记录。
4. 权益一致：Free已有3项目及多份收纳后仍可读取、继续、命名、更新、切换、删除恢复与新建；memory/首页/advanced/模板基础数量一致，其他高级门控不放开。
5. 仅保存：明确窗口/所选页面，空名生成可读标题；不关闭/移动页面，不混入其他窗口同网址页面。
6. 保存并收起：确认前可见范围、保存/关闭/固定保留数量；保存成功后才关闭预览确认普通页；固定/未选/无关页保留；取消/保存失败不关闭。
7. 结果/撤销：可查看对应项目；撤销回原窗口/原分组/固定状态并保留项目，界面即时刷新；部分失败真实显示。
8. 持续使用：迁入与新项目都可重命名、更新同一ID、继续补缺不重复/不删记录；最近保存排序正确。
9. 安全切换：迁入项目可作来源/目标；目标不完整不收起来源，共享/固定/无关页面保留；失败重试不退化。
10. 复杂恢复：新项目真实路径覆盖同时create与group失败、成功组/窗口后来消失、metadata失败页关闭；重试不分裂组、不无限失败、不重复开页、不移动预先已开页。
11. 兼容闭环：后台快捷键、legacy/portable导入、merge/replace及反复导入、旧回收站及新项目删除恢复均产生统一项目；备份往返无双份；搜索/omnibox/advanced无重复或失联项目；旧ID相关路径可用。
12. 四语言与布局：en/zh-CN/zh-TW/ja统一项目文案，无免费3工作区/Pro无限工作区过期主张；固定底栏/内容独立滚动/移动宽度/键盘焦点/语言切换草稿保持。
13. 验证与边界：保留原328测试适用行为覆盖，新增真实行为测试；syntax及release/projects/i18n/layout与受影响memory流程通过；不改AGENTS/CLAUDE/权限/真实用户资产，不提交发布；8份旧ZIP不变，输出新试用包。
