# 多语言支持

任务 ID：2026-11-04-multilingual。Forge L2；开发前由独立只读规划调用确定方案。

用户原始需求：**增加多语言支持。**

## 目标与边界

支持 English、简体中文、繁體中文、日本語。设置提供“跟随浏览器”和手动选择，保存在本地，切换后即时更新界面，不重载页面、不丢失输入或结果。不翻译用户标题、项目名、网址、正文、平台名称及模型输出。不增加权限、依赖、翻译服务；不修改 AGENTS.md / CLAUDE.md，不提交、推送或发布。保留所有既有未提交改动。

## 现状与方案

现有英文及简体中文各 519 个词条，语言加载时固定。搜索平台另有独立 COPY，导航和浏览记忆只初始化时翻译；日期有硬编码及浏览器默认格式。

保留 t/tPlural 接口，统一语言初始化、持久偏好及变化事件。偏好白名单 auto/en/zh-CN/zh-TW/ja。按 navigator.languages 顺序匹配首个支持语言，再 navigator.language、Chrome 界面语言，最后英文。中文显式 Hant/Hans 优先；无脚本 TW/HK/MO 为繁体，其余中文为简体。Intl.PluralRules 的 one 对应单数，其他对应复数。未知键安全回退英文或键名。

语言服务读取完成后进行首次本地化；切换仅更新文案及已有状态展示，不重建控制器。读失败按自动继续；保存失败保留原偏好并提示。新增 extension/locales/zh-TW.js、ja.js，以 globalThis.TabOutLocales 注册并由 i18n.js 合并。完整翻译键不能用合并英文冒充。搜索平台接入统一词典；新增 _locales/zh_TW、ja 元数据。Chrome 管理页元数据仍由 Chrome 自身语言决定。本轮不改备份格式，不强制跨窗口即时切换。

## 文件归属

- 主开发者：i18n.js、index.html、app.js、必要样式、三个 UI 控制器、搜索平台设置、语言服务与词典测试、初始化集成。
- 繁体/日语开发者：各自新语言文件及对应 _locales 元数据，互不编辑主开发者文件。
- 主会话：Chrome 验证脚本、文档、任务记录、证据、集成与打包。

## 风险

不能以 renderStatus(true) 切换语言，避免覆盖模型表单。项目及平台编辑草稿也需保留。权限请求前不得插入异步语言读取。完整翻译为开发翻译，未经过母语者审校。最多两轮独立验收修复，不降低标准。
