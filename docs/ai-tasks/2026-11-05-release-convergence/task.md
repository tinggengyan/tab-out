# 发布前体验收敛

任务 ID：2026-11-05-release-convergence。跨模块分阶段实现，互不重叠的 UI 与检索模块分别开发，集成后独立验收。未经授权不提交、推送或发布。

## 来源与目标

用户接受 2026-11-05 产品审视建议，要求正式处理发布前体验问题。主路径：**收起一组页面 → 回来继续 → 找回旧文章**。沿用现有视觉风格；保留标签页首页首屏操作，避免搜索或营销内容再次挤占它。

审视证据为用户 Chrome 的真实截图与当前源码；报告在本机 `tab-out-audit-2026-11-05/report.md`。已发现命名与入口重复、短词被网址片段误命中、摘要过长、空状态不符实际、备份范围和收费承诺不清晰。一次查询不构成整体找回质量评估。

## 约束与方案

- 保留全部既有未提交改动。不改写 AGENTS.md、CLAUDE.md，不清除或破坏迁移工作区、收纳组、稍后查看及浏览记忆数据。
- 将“项目”入口改为“已保存”，统一查看所有既有 workspace、tabGroups、deferred；规则、模板、归档内容等高级管理仍可访问。保存名称可选，自动生成可读默认名称。
- 原标签页首页仍有收纳、继续和稍后查看快捷操作。普通窗口用可读序号与页面信息，不显示内部数字 ID。
- 基础本地搜索覆盖打开、已保存和浏览记忆。保留其他配额与高级自动化授权，不改变模型、权限、密钥及数据保留策略。
- 检索修正短词边界与网址噪声；新内容抽取按阅读块组织，既有正文查询时清理并截短摘要，原文引用仍依据实际保存的正文校验。不限主题或站点；保留论坛阅读内容、排除输入与编辑草稿。
- 普通备份与浏览记忆备份明确分开；设置可发现模型与记忆管理。未完成同步不售卖；未配置结账不展示购买承诺；保留已有授权管理。
- 所有新增文案覆盖 en、zh-CN、zh-TW、ja。保留固定底栏、内容滚动、语言切换及用户草稿/选择。

## 开发归属

1. UI Developer：app.js、index.html、样式、UI 控制器、四语言、UI 单元/集成测试；可增加已保存阅读适配器与安全继续辅助模块。不得改记忆后台/检索算法或 Chrome 工具。
2. Search Developer：内容抽取、记忆检索服务、新增纯检索辅助模块、对应单元测试及最小后台 importScripts 接线。不得改 UI/语言、权限、仓库格式或 Chrome 工具。先告知 UI 新结果接口。
3. 主会话：Chrome 验证工具、受控检索评估、文档、任务记录、集成与打包；不覆盖开发者拥有的源文件。新 Tech Lead 只读独立验收。
