3.0 重建时删除了 2.x 的统一搜索（`../2026-11-11-soul-rebuild/design.md` 第 53 行）。本设计是波洛重新决定加回的、范围更小的搜索，不恢复 2.x 的 omnibox、命令面板、网站别名等。

## 2. 目标、非目标、反目标

- **目标：** 在一个地方按关键词找回页面，不管它现在是开着、在稍后查看、在收纳里、在书签里，还是只在历史记录里。
- **非目标：** AI 或语义搜索；网页正文搜索；搜索结果上的批量操作；omnibox 关键字；在 Tab Out 里管理书签或历史记录。
- **反目标（出现即失败）：**
  - 页面发出任何 http(s) 请求；
  - 安装或更新时多出权限提示；
  - 修改书签或历史记录；
  - 首页平时多出一个以上的常驻控件。

## 3. 入口与浮层

- **入口：** "打开的标签页"标题旁边的"搜索 /"按钮，以及 `/` 键。
  - 焦点在输入框、文本区或可编辑元素里时，`/` 不触发搜索。快捷方式对话框打开时同样不触发。
  - **已知限制：** 新开标签页时焦点在地址栏，要先点一下页面，`/` 才生效。这是 Chrome 对扩展新标签页的限制。
  - **已知限制：** 一个标签页都没打开时，"打开的标签页"整块隐藏，按钮也跟着隐藏，只剩 `/`。
- **浮层：** 页面变暗，中间是面板，从上到下依次是：
  - 输入框；
  - 结果列表；
  - 底栏：按键提示和本次搜索范围。

  按 `esc`、点遮罩或执行一个结果都会关闭浮层，焦点回到打开前的位置。
- **四个状态：**
  1. **刚打开：** 显示一行提示。未授权时，下面有"也搜索书签和历史记录"卡片。
  2. **未授权时搜索：** 只搜三个本地来源，授权卡片留在结果最下面。
  3. **已授权：** 多出"书签""历史记录"两组，授权卡片不再出现。
  4. **没有结果：** 写明搜过哪些来源，并建议换个词。未授权时仍显示授权卡片。

## 4. 结果与回车

**匹配规则：**
- 输入按空白拆成词，不区分大小写。
- 标题或网址包含全部词才算命中。
- 收纳记录的名字只用来命中这条记录本身，不会让记录里的每一页都算命中。

**分组顺序固定：** 打开的标签页 → 稍后查看 → 已收纳 → 书签 → 历史记录。
- 空的组不显示。
- 每组先显示 3 条，其余收起为"还有 N 条"，点开或回车可展开。

| 结果 | 显示 | 回车或点击 |
|---|---|---|
| 打开的标签页 | 标题、域名、"本窗口"或"其他窗口" | 切换到该标签页，并把它所在的窗口提到前面 |
| 稍后查看 | 标题、域名、保存了多久 | 在新标签页打开 |
| 收纳记录（整组，名字命中时出现） | 名字、页数、日期 | 关闭浮层，在右栏展开并高亮这条记录；不恢复 |
| 收纳里的一页 | 标题、域名、所在记录 | 打开这一页，并把它从记录里移出；已经开着就切换过去 |
| 书签 | 标题、域名、所在文件夹 | 在当前标签页打开，替换 Tab Out 页面 |
| 历史记录 | 标题、域名、最近访问时间 | 同书签 |

- **只收这些协议：** 书签和历史记录只收 `http:`、`https:`、`file:` 地址。`javascript:` 书签小工具等其他协议不出现在结果里。
- **历史记录去重：** 已经出现在前面四组里的网址，不再在历史记录里重复。
- **历史记录的数据来源：** 打开浮层时读取最近 3000 条历史记录，在本地按上面的规则匹配。另外，每次输入时再用 Chrome 自带的历史搜索查一次，用来补上更早的记录。两部分合并后，统一按本节规则过滤，按最近访问时间排序。

## 5. 权限

- **manifest 改动：** 新增 `"optional_permissions": ["history", "bookmarks"]`；`permissions` 仍恰为 `tabs, storage, favicon`。可选权限不会在安装或更新时弹出提示。
- **授权流程：** 只在点击"开启"时调用 `chrome.permissions.request`，一次申请两项。
  - 用户允许：浮层直接进入状态 3。
  - 用户拒绝：停在状态 2。
  - 每次打开浮层都用 `chrome.permissions.contains` 重新检查，在 Chrome 里撤销授权后会回到未授权状态。
- **只读：** 只读取书签和历史记录，不创建、修改或删除。由静态契约测试保证。

## 6. 约束

- 不新增运行时依赖。
- 纯逻辑放在 `extension/lib/search.js`，界面放在 `app.js`。
- 标题等文本一律转义后再高亮。
- 图标用 `_favicon`。
- 文案只有 `en` 和 `zh-CN` 两种，键和占位符必须一致。
- 3.0.0 尚未发布，版本号不变，变更记入 CHANGELOG 3.0.0。
- 首屏常驻控件上限从 30 调到 31（波洛 2026-11-12 同意），多出的一个就是"搜索"按钮。

## 7. 验收

- **单元测试：** 覆盖分词与匹配、分组顺序、收纳记录与单页、协议过滤、历史去重与排序、高亮转义、书签文件夹路径、"今天/昨天"判断。
- **静态契约：**
  - 可选权限恰为 `history`、`bookmarks`；
  - `app.js` 不调用书签或历史记录的写接口；
  - `lib/search.js` 在 `app.js` 之前加载。
- **e2e 未授权场景：** 中英文各跑一次，检查以下几项：
  - 按钮和 `/` 能打开浮层，`esc` 能关闭；
  - 三组结果正确，授权卡片出现；
  - 回车切换标签页；
  - 回车打开收纳单页，并把它移出记录；
  - 回车展开收纳记录；
  - 没有结果时显示说明；
  - 标题里的标签按文本显示；
  - 全程零 http(s) 请求。
- **e2e 已授权场景：** 单独一套测试，用补全了权限的扩展副本运行，检查以下几项：
  - 书签显示所在文件夹；
  - 历史记录去掉已开着的页面；
  - 回车在当前标签页打开。

## 8. 留给实现的决定（Claude 的决定）

- "窗口 2"改为"本窗口 / 其他窗口"。原因：Chrome 的窗口编号对人没有意义。
- 组名用右栏已有的"已收纳 / Stashed"，不用效果图里的"收纳"，和右栏标题保持一致。
- 从收纳打开单页时，新标签页放在前台。原因：从搜索执行就是要去看这一页。右栏里点单页仍在后台打开，行为不变。
- 读取最近 3000 条历史记录，是速度和覆盖面的折中，数字可调。
