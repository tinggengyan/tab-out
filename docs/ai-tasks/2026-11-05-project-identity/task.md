# 恢复 Project 独立入口与产品边界

Forge L2；用户明确采纳恢复Project的建议，并授权根与产品经理角色达成一致后直接开发交付。只读产品/技术规划由 `/root/project_pm_alignment` 完成，未把AI产品评审称为真实团队成员。

## 背景与共识

此前发布前收敛将Projects改名Saved，workspaces、tabGroups、deferred合并主列表/数量，归档也会抑制项目空态。用户指出Project消失；根承认概念调整未经充分说明。用户这次授权明确替代上一任务“改名已保存并混合展示”的要求，其余安全/搜索/恢复改进保留。

产品经理角色与根一致：Project表示持续推进的一件事，Saved表示存储状态。恢复熟悉入口即可，不新增导航能力。默认仍标签页，顶栏“标签页 / 项目 / 浏览记忆”（英文Projects）；主项目列表、计数和空态仅来自workspacesV2。临时收纳与稍后查看分别为项目列表之后的次级折叠区，标题/各自数量始终可见，默认折叠，归档仍可达且来源清楚。

创建、新建、保存到、继续/切换、首页快捷入口恢复项目语义，名称仍可选。统一搜索中的“已保存”可保留为跨类型概括，项目来源标记明确；不机械替换所有Saved。不新增存储/迁移，不自动把收纳变成项目，不改变既有项目名称或旧资产。
