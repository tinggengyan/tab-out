# 首页层级修复：默认回到标签管理

状态：实现及独立验收PASS，12项冻结标准全部闭合；详见[实现报告](implementation.md)和[验收报告](acceptance.md)。

日期：2026-11-04。L2，Forge规划／实现／独立验收。来源为用户反馈“搜索相关功能占满屏幕，正常Tab Out功能需要翻页”，见[截图审视](audit.md)。只读规划由独立 `dashboard_layout_plan` 完成；本合同在实施前冻结。现版本2.3.0，Node基线265/265通过，既有未提交改动全部保留。

## 目标、方案与范围

默认新标签页直接呈现当前标签和已有收纳。添加紧凑、在长内容中仍可用的同页导航“标签页／项目／浏览记忆”。复用原DOM与控制器，项目和浏览记忆各自按需显示，非当前视图 `hidden` 且不占布局或焦点顺序。不创建新路由、存储结构或额外模态层。重复Tab Out提示属于标签页视图，页脚工具全局可用。

导航使用普通button，名称、aria-controls、唯一aria-current状态完整。固定ID：`dashboardNavTabs`、`dashboardNavProjects`、`dashboardNavMemory`；包装视图：`dashboardTabsView`、`dashboardProjectsView`、`dashboardMemoryView`。保留原工作台、表单和弹窗ID。

只在手动切换时记录与恢复各视图scrollY，focus使用preventScroll；返回标签页聚焦其导航。刷新始终标签页，不持久化上次打开的视图。后台重绘不切视图、不夺焦点。保留项目原操作弹窗、浏览记忆原确认框，以及命令搜索等全局弹窗。切换不修改业务数据、不自动搜索、不请求权限、不开启采集、不自动勾选内容发送同意。

现有主栏min-width600px与280px／320px两收纳栏同时显示有宽度风险，允许在本次响应布局中修复；不得隐藏存量内容满足测试。沿用暖色样式，不重做无关界面。

不改业务后端、服务、存储、权限或版本；不修改AGENTS.md／CLAUDE.md，不提交、推送、发布或操作个人Chrome数据。真实模型质量和真实内网站点联调继续不在本轮范围。

## 冻结验收标准

| ID | 可观察通过条件 |
| --- | --- |
| AC1 默认首屏 | 真实Chrome、100%缩放，1440×900和1366×768，完成首次引导、有正常标签和已有收纳。无需滚动，首张当前标签卡top≤200px；有重复Tab Out提示时≤280px。卡片标题与至少一条标签记录可见；已有收纳标题和首项也在首屏。 |
| AC2 默认层级 | 首次载入与刷新仅标签页显示，项目／浏览记忆不占布局，无明显先展开再隐藏；从另外两个视图刷新均回标签页。首次引导原规则不变。 |
| AC3 入口与内容 | 三个文字导航一键进入对应视图，活动态唯一，节点ID唯一、无控制器重建或事件丢失；全局页脚三个视图均可用。 |
| AC4 返回与滚动 | 足够长的种子内容，标签页scrollY至少400px后切到项目／记忆再返回，恢复±2px；标签页入口持有可见焦点。项目／记忆各自scrollY也能恢复，导航不遮挡可交互内容。避免click辅助函数scrollIntoView先改变待测位置，使用真实坐标点击并测量。 |
| AC5 视图内状态 | 记忆查询、筛选、结果、选择及项目列表切换后保持。隐藏视图异步完成或后台标签刷新不自动切换、不跳顶部、不把焦点移进隐藏内容。 |
| AC6 弹窗与键盘 | 项目保存／收起／恢复和记忆删除／清空确认正常；Escape只关最上层弹窗，Tab／ShiftTab不逃出，关闭后回可见触发点及所属视图。命令搜索快捷键三个视图都可打开、关闭并恢复可见焦点。 |
| AC7 响应布局 | 390×844与两个桌面视口，三个视图scrollWidth≤innerWidth+1；导航、搜索、项目操作、页脚可访问，长标题／URL不撑破。桌面覆盖仅收纳组、仅稍后阅读、两者都有的正常存量数据。 |
| AC8 数据不变 | 隔离环境关闭自动快照／暂停采集，切换与刷新前后，收纳组、稍后阅读、项目、记忆正文和设置保持，无需迁移／清空。导航不写业务数据、不自动搜索／申请权限。 |
