# 项目工作台开发方案

## 结构与兼容

保持 MV3 + 原生 JS/CSS/HTML，扩展直接加载，无运行时包依赖。工作区仓库仍是项目唯一数据源，增加可选布局会话，旧 entries 列表继续供搜索、规则及旧项目使用。

新增项目服务编排“预览 → 保存 → 恢复 → 收起”，界面只调用服务，不自行组合危险动作。用 sessionAdapter 负责浏览器能力，operationService 负责可重试的撤销。新 UI controller 与样式可独立模块化，再用最小 app 钩子接入。

## 阶段与工作归属

| 阶段 | 实现 | 验证 |
| --- | --- | --- |
| 恢复与存储基础 | original 模式、窗口创建失败保护、原生组权限、部分 Undo 重试、会话存储和失效 | API 行为单测先失败后通过；旧存储/备份/操作测试回归 |
| 项目事务 | 严格选择当前窗口成员、版本指纹、保存先于关闭、缺失复查、共享页保护、目标失败保留源 | 混合项目、额度/空选择/存储失败/预览过期/创建失败故障注入 |
| 产品界面 | 项目主入口、候选搜索勾选、明确来源选择、切换预览、三类结果、备份状态、中英文 | 专属 UI 测试、真实鼠标点击、键盘与布局核验 |
| 集成与交付 | 自动启动隔离 CFT、原有及新增旅程、截图、版本与 ZIP | 新鲜全套测试、语法/manifest/包校验、独立验收 |

后端与 UI 仅在 task.md 冻结 API 下按文件并行；主会话持有 tools 与文档，不回退既有修复。规划和验收使用独立上下文。

## 安全状态与错误

空选择、过期预览、额度不足、重入、目标等于来源都在服务边界拒绝。项目写入失败时无关闭动作；恢复目标失败时保持来源打开；关闭部分失败保留真实操作记录。重试只处理缺失/失败项，不能把恢复成功页面再次打开。每一种非完整成功在界面有明确说明。

不能把窗口 ID 当跨重启身份；只用于本次浏览器会话原位撤销。持久的项目身份为 workspace ID。所有页面和项目文字安全渲染，备份不含支付私钥或原始遥测内容。

## 可重复的验证入口

- 固定 Node 22+（本机实际使用 Node 24.15.0）；现有测试入口为 `node --test`。
- `tools/run-chrome-e2e.mjs` 自动找已安装的 Chrome for Testing 或接受 `CHROME_FOR_TESTING` 路径，为每组旅程创建并销毁独立临时配置。
- 既有 `tools/chrome-e2e.mjs` 回归搜索、收纳撤销、快照、授权边界、备份和失败恢复。
- 新 `tools/chrome-project-e2e.mjs` 验证混合窗口的项目保存、收起、撤销、共享页切换、失败重试、持久化和备份。
- 截图与原始结果写入 `evidence/`；仅使用测试网页，不连接或清理用户日常浏览器。

## 交付方式

提供修改后的 `extension/`、可安装 ZIP、完整需求/视觉/技术方案、实际测试与独立验收记录。现有本地安装通过重新加载扩展及页面升级；不得卸载或清空已有数据。上架、生产付款与公网发布不在本轮授权范围内。
