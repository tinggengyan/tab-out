# Tab Out 项目工作台：详细需求

日期：2026-11-01。用户原始目标：“我自己就是核心用户，制定详细需求；研究视觉效果；提供开发方案；提供可用产品。开工”。

## 产品目标与默认假设

为当前真实使用 Tab Out 的用户交付可安装的 Chrome 扩展增量。核心任务是保存正在处理的项目、放心收起、继续另一个项目，以及下次回来补齐相关页面。用户无需建立新账号、运行服务或先配置自动化规则。

用户已明确：**多个项目混在同一个窗口**。以当前窗口作为候选范围，不能把整个窗口等同为项目。新建项目默认零选或沿用用户在标签网格中明确勾选的页面；选择更新已有项目时，仅按其成员匹配本窗口页面，再允许手动调整。已有工作区就是项目，不建立第二套相互独立的项目数据。

## 本轮范围

| 编号 | 能力 | 用户可观察的行为 |
| --- | --- | --- |
| R01 | 项目主入口 | 新标签页上部提供项目保存入口和已保存项目，明确提示先选择属于项目的标签；不必先找页脚管理入口 |
| R02 | 可选择的保存 | 普通对话框输入项目名、选择当前窗口网页，查看保留/排除项；保存不等于关闭 |
| R03 | 保存并收起 | 明确确认关闭哪些标签；项目持久化成功后才关闭，且提供即时撤销 |
| R04 | 继续项目 | 预览已有与缺失页面；默认只打开缺失页面，不重复创建，不移动其他项目已打开的标签 |
| R05 | 切换项目 | 显示当前来源和目标；先保存来源、恢复目标，目标恢复失败时保留来源；成功后再收起已确认的来源标签 |
| R06 | 真实恢复与撤销 | 保留支持范围内的窗口、顺序、固定状态与原生分组信息，显示实际结果和失败项 |
| R07 | 清楚的中间状态 | 操作时禁用重复提交，完成后立即更新项目、标签计数和卡片；失败不会伪装成成功 |
| R08 | 本地数据与备份 | 提供本地保存说明、备份提醒及一键导出；完整备份包含项目布局信息 |
| R09 | 旧数据兼容 | 旧工作区、收纳、历史、搜索和备份继续工作；没有布局的旧项目可以按网址列表恢复 |
| R10 | 可直接使用的交付 | 单元/集成检查、隔离 Chrome 扩展测试、实际截图、安装包及明确的安装/升级说明 |

## 主要用户旅程

### A. 保存当前项目

1. 用户打开 Tab Out，看到当前窗口的可保存标签数量。
2. 点击“保存项目”，输入项目名或选择更新既有项目，跨域名勾选需要的标签；默认不会全选混合窗口。
3. 页面说明浏览器内页不会保存，固定标签是否属于保存范围、是否会被关闭应明确区分。
4. 点击“保存”，项目持久化后显示成功和标签数量；原网页仍打开。
5. 新项目出现在项目列表，名称和时间信息无需刷新即可看到。

### B. 保存并收起

1. 用户选择项目与标签，选择“保存并收起”。
2. 确认界面显示将关闭的数量，以及保留的固定页、浏览器内页等。
3. 先写入项目和恢复数据；写入失败时不关闭任何页面。
4. 仅关闭当前确认范围内的标签。Tab Out 页面、其他窗口、未勾选页和默认保留的固定页继续存在。
5. 显示真实关闭结果及“撤销”；撤销只恢复实际关闭成功的页面。

### C. 继续与切换

1. 项目卡片展示总页面、已打开及待补齐数量。
2. “继续”默认补齐缺失页面；全部已经打开时给出可理解反馈，不制造重复页面。
3. “切换”打开预览，明确选择需要收起的来源项目，说明它将保存到哪里、目标缺失数量及将收起的来源标签；同窗其他项目保持打开。
4. 来源保存成功后恢复目标；任一目标恢复失败，保留来源并展示结果，允许后续安全重试。
5. 恢复成功后关闭确认过的来源标签；与目标共享且正在复用的页面、固定页不在关闭集合中。
6. 操作结束后立即刷新，并允许撤销本次收起。

## 安全与边界

- 默认只处理 HTTP/HTTPS 网页；浏览器内页、扩展页、无痕窗口不进入项目关闭流程。
- 明确区分“保存固定页”和“关闭固定页”；默认保留固定页，不能因切换而误关。
- 项目更新须明确选择覆盖对象；不按名称自动猜测覆盖项目。
- 保存失败不关闭；目标恢复失败不收起来源；部分关闭失败显示真实数量并保留可恢复数据。
- 撤销回原窗口；原窗口已消失时新建对应窗口。创建窗口失败不可悄悄恢复到无关窗口。
- 标签恢复保留相对位置与支持的元数据，不承诺网页表单、滚动位置、登录状态或网页未保存内容。
- 原生分组能力需要正确权限；权限不可用时必须有可理解结果，不能默默宣称完整保真。
- 仅重复点击防护，不宣称解决所有跨扩展页面、跨窗口并发写入问题。
- 项目基础流程可以在既有免费额度内使用，保留现有授权体系；不要求配置付款来验证本轮功能。

## 视觉与交互验收

- 沿用现有暖白、墨色、鼠尾草绿；不换框架、不引入远程字体或运行时依赖。
- 主区域只突出“当前窗口”和“继续项目”，高级规则、历史等保留既有入口。
- 主操作有文字；新对话框不使用浏览器原生 prompt 输入项目名。
- 新区域正文以 14–16px 为基准，危险操作说明清楚；颜色之外也通过文字表明状态。
- 键盘可访问新按钮、表单和对话框；支持取消、焦点可见及提交期间禁用。
- 空列表、没有可保存标签、长名称、部分失败、重复恢复均有明确状态。
- 在桌面及窄窗口中无关键操作裁切、横向溢出或遮挡；保留已有选中/展开状态。

## 非目标

本轮不公开上架、不收费、不配置生产密钥、不做跨设备同步、团队协作或 AI 分类。OneTab/Session Buddy 专用导入不是当前自用核心旅程的前置条件，本轮不据此扩大交付范围。安装需要重新加载本地扩展，但不重装、不清空用户数据。

## 完成定义

开发前冻结技术方案和逐项标准；实现后以新鲜验证记录证明行为。至少覆盖保存不关页、保存并收起和撤销、只补缺失、共享页面保护、写入/恢复失败保护、旧项目兼容、原窗口和分组恢复、项目备份往返。真实浏览器测试使用全新临时配置和测试网页，不操作用户日常标签。交付后说明已验证与未验证范围。
