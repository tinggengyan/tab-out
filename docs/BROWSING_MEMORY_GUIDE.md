# 浏览记忆搜索使用指南

适用版本：Tab Out 2.3.0。已有安装重新加载扩展并刷新新标签页即可；不要卸载或清空存储。

## 开始使用

1. 点击新标签页顶部的“浏览记忆”，进入搜索视图，再展开“记录、模型与数据”。首页默认展示标签管理，搜索和设置不会占据首页首屏。
2. 点击开启正文记录，按 Chrome 提示允许访问网页。此后记录你打开页面中能提取的已加载阅读内容，支持普通公开、登录后和内网页面，不限制题材和域名。可以随时暂停或排除站点。
3. 点击导入最近30天历史，单独授予历史权限。旧历史只有标题、网址和访问时间；未提前记录的正文无法还原。达到导入上限时界面会提示。
4. 输入主题或记得的大意，选择时间与本地／AI搜索。结果显示原链接、访问时间、正文片段与“仅元数据／有正文”状态。

也可使用底栏搜索或 Cmd/Ctrl+K，在 Free 中本地查找打开的标签、已保存内容和过去的浏览记忆。浏览记忆独立视图提供时间选择、AI扩词、正文重排和摘要。全局设置可直接打开模型与记忆管理、请求独立记忆备份。

点击顶部“标签页”回到当前标签；同一页面切换保留查询、结果、选择及各视图滚动位置。刷新或重新打开新标签页始终先显示标签页，不会自动进入浏览记忆。

## 配置已有模型服务

- **服务地址：** 例如 `https://your-service.example/v1`，也支持完整 `.../chat/completions` 地址。自定义路径保留；根地址会使用 `/v1/chat/completions`。
- **模型名：** 填服务提供的模型标识，不是界面显示名称。
- **API Key：** 按服务需要填写；无密钥的本机服务可留空。保存后只显示已配置状态，不回显密钥；未编辑空白框会保留旧密钥，主动清空再保存会删除密钥。更换服务来源会清除旧密钥，除非该次明确填写新值。
- 点击保存和测试连接，允许访问该服务来源。该版本采用 Chat Completions 协议，不要求 embeddings、工具调用或 JSON mode。

AI搜索默认只把问题发给模型扩展关键词，网页内容仍在本机检索。若要让模型比较候选或概括选中内容，勾选本次允许发送内容；此操作包括公开、登录后和内网内容，应按你选择服务的用途使用。摘要依据实际发送的有限片段，每条保留来源和原文摘录，不能替代核对完整原文。

接口不可用、限流或返回格式不正确时，搜索会说明错误并保留可取得的本地结果。真实模型理解质量、实际内网站点提取效果与响应速度，需要配置你的服务后继续联调。本次开发验证使用本地协议替身，不把模拟结果当作真实模型效果。

## 找回后继续使用

- 点击原文标题会优先切换至已经打开的同一网址。
- 勾选结果后可批量打开、保存到既有集合或删除；保存不会关闭网页，沿用当前项目额度。
- 概括最多选8个有正文的结果，需要本次内容发送许可；只有历史元数据的结果不能生成正文摘要。
- 关闭内容许可会取消尚在进行的搜索，阻止后续候选正文发送；已经发出的请求无法撤回。
- AI 搜索进行中切回本地也会取消旧请求，即使此前没有勾选正文许可；迟到结果不会覆盖新的本地查询。

## 记录、容量与备份

默认保留90天，最多5000条／32MiB；每页正文最多30000字符，复杂页面可能只取得部分内容或没有正文。浏览器限制、图片／视频、尚未加载和特殊文档内容不保证可提取。按实际访问时间筛选，不把打开过说成读完。

排除站点只阻止未来记录，已有内容需另行删除。删除当前记录后，该页在同一个仍打开的文档中不会立即再次记录；以后重新访问仍可重新记录。清空记忆会同时暂停记录。密钥、模型地址和设置不进入记忆备份。

使用“导出浏览记忆”取得独立JSON文件，导入时先预览再确认。普通 `tab-out.config` 仅包含原有扩展资产，不含这个正文库；迁移设备前需分别导出。记忆文件可能含私人正文，应按自己的数据保管方式保存。
