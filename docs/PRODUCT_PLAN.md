# Tab Out 商业化产品方案

> 文档状态：Draft v1.0  
> 更新日期：2026-08-09  
> 适用范围：Chrome Manifest V3 扩展  
> 对应开发方案：[DEVELOPMENT_PLAN.md](./DEVELOPMENT_PLAN.md)

## 1. 产品结论

Tab Out 应从“漂亮的标签清理页”升级为“默认本地、可靠可恢复的浏览工作台”。

核心承诺：

> 放心关闭，随时回来。

商业化不依赖广告，也不出售浏览数据。免费版解决标签混乱；Pro 版解决工作现场丢失、跨项目切换和重复整理；Sync 订阅解决跨设备连续性。

## 2. 背景与现状

### 2.1 已有能力

- 新标签页替换及按域名分组展示
- 首页类标签聚合
- 单个、分组和全量关闭
- 重复标签检测与清理
- 跨窗口跳转标签
- 稍后查看、完成归档与归档搜索
- 一键收纳、整组或单页恢复
- 自定义快捷入口
- 本地配置导入、导出
- 中英文界面
- 数据存储于 `chrome.storage.local`

### 2.2 当前问题

- 关闭和删除缺少统一撤销，用户不敢放心操作。
- 收纳仅保存 URL 与标题，无法还原窗口、顺序、固定标签和原生标签组。
- 没有自动快照，浏览器崩溃、误关窗口和设备故障后缺少保障。
- 按域名分组适合清理，不适合跨站点项目协作。
- 搜索只覆盖部分归档数据，无法快速找到全部浏览资产。
- 纯本地数据缺少可选备份和跨设备能力。
- 当前免费能力较完整，但尚无足以支撑付费的核心差异。

## 3. 产品目标与非目标

### 3.1 12 个月目标

1. 建立“安全关闭与可靠恢复”的明确心智。
2. 发布具备付费价值的个人 Pro 版本。
3. 验证加密同步的订阅需求，再投入服务端建设。
4. 保持默认本地、无广告、不出售数据的差异化定位。

### 3.2 非目标

- 首期不做团队实时协作、SSO 或企业后台。
- 首期不做通用任务管理器、笔记工具或 AI 内容平台。
- 不默认上传标签 URL、标题或浏览历史。
- 不自动关闭用户标签；任何自动化关闭都必须预览、确认且可撤销。
- 不用广告或联盟链接破坏新标签页体验。

## 4. 目标用户

### 4.1 核心用户：多项目知识工作者

- 同时保持 20–100 个标签
- 经常在多个项目间切换
- 担心误关或浏览器崩溃导致工作丢失
- 愿意为节省恢复时间付费

典型职业：开发者、设计师、产品经理、研究人员、自由职业者。

### 4.2 次级用户：标签囤积者

- 会打开大量内容但很少整理
- 需要低学习成本的清理建议
- 更偏好一次买断，不一定接受订阅

### 4.3 后续用户：小团队

- 需要共享项目链接集合与模板
- 需要统一计费和权限
- 在个人 Pro 与 Sync 验证前不作为开发重点

## 5. 产品原则

1. **可逆优先**：所有破坏性操作都有即时撤销或回收站。
2. **恢复保真**：恢复的是工作现场，不只是一串 URL。
3. **默认本地**：联网能力必须由用户主动开启。
4. **价值先于智能**：先把保存、搜索、恢复做可靠，再考虑 AI。
5. **渐进复杂**：新用户无需先创建工作空间即可获得价值。
6. **数据可携带**：用户随时可以完整导出，不以数据绑架付费。

## 6. 信息架构

新标签页保留当前“打开的标签页”主视图，并增加全局导航：

- **现在**：当前所有窗口和标签，支持域名或窗口视图
- **空间**：用户命名的项目工作空间
- **收纳**：主动保存的标签集合
- **历史**：自动快照与关闭记录
- **稍后**：待读清单及归档
- **搜索**：跨当前标签、空间、收纳、历史和稍后的统一搜索
- **设置**：隐私、快照、自动化、导入导出、套餐和同步

## 7. 版本与功能范围

### 7.1 Release 1：Trust 基础版

目标：让用户敢于关闭标签，并具备市场发布质量。

#### PRD-101 统一撤销

- 关闭单页、关闭域名、关闭全部、收纳、删除收纳组后显示撤销入口。
- 关闭操作保留 30 秒即时撤销；删除数据进入回收站。
- 撤销应恢复窗口、顺序、固定状态和原生标签组，能力不足时明确提示。
- 连续操作可按最近一次逐步撤销。

验收：上述操作均可恢复；扩展或新标签页刷新后，回收站仍存在。

#### PRD-102 回收站

- 保存最近删除的收纳组、工作空间和稍后项目。
- 默认保留 30 天，可手动清空或永久删除。
- 免费版与 Pro 均可访问，不将数据安全作为付费勒索点。

#### PRD-103 数据安全与迁移

- 所有网页标题、URL 和用户输入安全渲染。
- 存储数据具备 schema 版本与向前迁移。
- 导入前校验格式、数量和字段；展示预览及冲突策略。
- 提供完整数据导出。

#### PRD-104 首次使用与权限解释

- 三步 onboarding：看见、收纳、恢复。
- 清晰解释 `tabs`、`storage` 权限的用途。
- 首次全量关闭或收纳前展示结果预览。

### 7.2 Release 2：Recovery Pro

目标：形成第一项可以收费的核心能力。

#### PRD-201 完整会话模型

保存并恢复：

- 多窗口结构
- 标签 URL、标题和顺序
- active 与 pinned 状态
- Chrome 原生标签组名称、颜色、折叠状态
- 捕获时间、设备标识、来源和用户备注

#### PRD-202 自动快照

- 浏览器启动后创建基准快照。
- 标签结构发生实质变化后延迟合并保存，避免每次事件都写盘。
- 支持手动“保存当前现场”。
- 历史列表按时间组织，可预览差异后恢复。
- 恢复方式：覆盖当前窗口、新建窗口、合并到当前窗口。

免费版：最近 3 个自动快照、7 天回收站。  
Pro：90 天历史、无限手动快照、30 天回收站。

#### PRD-203 恢复冲突处理

- 恢复前提示将打开的标签数和窗口数。
- 可跳过已打开的重复 URL。
- 特殊页面或无权限 URL 明确标识为不可恢复。
- 部分失败不回滚已成功标签，输出恢复报告并允许重试。

### 7.3 Release 3：Workspace Pro

目标：从清理工具升级为高频项目工作台。

#### PRD-301 工作空间

- 创建、重命名、删除、置顶和排序空间。
- 设置颜色、图标和说明。
- 将当前窗口、域名组或选中标签保存到空间。
- 从空间打开全部、部分或仅缺失标签。
- 删除空间进入回收站，不影响当前已打开标签。

免费版最多 3 个空间；Pro 不限数量。

#### PRD-302 拖拽与批量操作

- 标签可在空间和收纳组间拖拽。
- 支持多选、移动、复制、删除和打开。
- 拖拽失败不丢数据，键盘操作具备等价能力。

#### PRD-303 自动归类规则

- 基于完整域名或 URL pattern 自动建议归类。
- 规则默认只建议，不自动关闭或移动。
- 用户可开启自动加入空间。
- 提供白名单和规则命中预览。

#### PRD-304 空间模板

- 将空间结构保存为模板。
- 提供空白、开发、研究、晨间启动等基础模板。
- 模板默认不包含私人 URL，除非用户明确选择。

### 7.4 Release 4：Find & Automate Pro

#### PRD-401 全局搜索

- 同时搜索当前标签、空间、收纳、快照和稍后项目。
- 支持标题、URL、域名、空间、类型和时间过滤。
- `Cmd/Ctrl+K` 打开命令面板，支持全键盘操作。
- 搜索结果标识来源，并提供跳转、恢复、移动等上下文动作。

#### PRD-402 地址栏与快捷键

- 支持 omnibox 搜索历史资产。
- 提供可配置命令：打开 Tab Out、收纳当前窗口、保存快照、打开搜索。

#### PRD-403 清理建议

- 提示重复标签、长期未访问标签和标签过载。
- 显示建议影响范围，默认不自动执行。
- 规则可以忽略域名或固定标签。

### 7.5 Release 5：Encrypted Sync

是否开发由 Release 2–4 的留存与付费验证决定。

#### PRD-501 可选账户与设备

- 不登录仍可使用全部本地能力。
- 登录后展示设备列表、最后同步时间和撤销设备权限。

#### PRD-502 端到端加密同步

- 标签内容在本地加密后上传。
- 服务端不持有可解密内容的密钥。
- 提供恢复码，明确丢失恢复码的后果。
- 冲突采用可解释、可恢复的合并机制。

#### PRD-503 同步范围

- 同步工作空间、收纳、稍后、设置和手动快照。
- 默认不同步完整自动历史，用户可主动开启。
- 支持暂停、立即同步和导出服务器数据。

## 8. 套餐与定价假设

### 8.1 Free

- 当前标签仪表盘与域名分组
- 重复清理与基础收纳
- 稍后查看和导入导出
- 3 个工作空间
- 最近 3 个自动快照
- 7 天回收站

### 8.2 Pro Lifetime

- 建议首发价：US$19，稳定价：US$29
- 无限工作空间
- 90 天快照历史与无限手动快照
- 完整标签组恢复
- 高级搜索、命令面板、规则与模板
- 30 天回收站

### 8.3 Sync

- 建议：US$2.99/月或 US$24/年
- 包含 Pro
- 端到端加密跨设备同步
- 多设备管理和持续云备份

原则：降级后用户仍能读取、恢复和导出已有数据；只限制继续创建付费资源。

## 9. 关键用户旅程

### 9.1 第一次获得价值

1. 用户安装并打开新标签页。
2. Tab Out 自动展示当前标签，无需注册。
3. 用户点击收纳，看到操作预览。
4. 标签被关闭并保存，界面提示可撤销。
5. 用户恢复收纳组，确认现场没有丢失。

### 9.2 Pro 转化时刻

1. 用户访问历史，看到超过免费额度的旧快照仍被列出但不可打开。
2. 产品展示该快照的时间、窗口数和标签数，不隐藏价值。
3. 用户可升级 Pro 或导出数据。
4. 购买后立即解锁，不要求重新捕获数据。

不在用户刚误删数据时弹出付费墙。

### 9.3 同步开通

1. 用户主动选择“在另一台设备继续”。
2. 产品解释加密模型和恢复码责任。
3. 创建密钥并要求确认恢复码已保存。
4. 初次同步展示项目数量和进度。

## 10. 指标体系

### 10.1 北极星指标

每周成功恢复的工作现场数（Weekly Successful Restores）。

### 10.2 激活指标

- 安装后 24 小时内首次收纳率
- 安装后 7 天内首次恢复率
- onboarding 完成率
- 首次收纳后的撤销率与失败率

### 10.3 留存与价值指标

- D1、D7、D30 活跃留存
- 每周快照预览/恢复用户占比
- 每用户空间数和手动快照数
- 搜索成功率：搜索后 60 秒内产生打开或恢复行为
- 恢复成功率及平均失败标签数

### 10.4 商业指标

- Free → Pro 页面访问率与转化率
- Pro 退款率
- Sync 试用 → 订阅转化率
- 月度订阅流失率
- 每付费用户支持请求数

### 10.5 隐私友好的采集原则

- 默认不采集 URL、标题、搜索词或空间名称。
- 只采集事件类型、数量区间、版本、错误码和耗时。
- 提供遥测开关和数据说明；未同意时只保留本地统计。

## 11. 发布门槛

### Trust 版本

- 所有破坏性操作具备撤销或回收站。
- 外部数据安全渲染，无已知高危注入问题。
- 存储迁移、导入异常和恢复失败有测试覆盖。
- 隐私政策、权限说明、支持渠道、商店素材齐备。

### Recovery Pro

- 100 标签、10 窗口、20 原生标签组场景恢复成功率 ≥ 99%。
- 恢复过程中刷新页面或 service worker 重启不会导致数据损坏。
- 快照写入不明显拖慢标签操作和新标签页首屏。
- 购买、激活、退款和离线宽限流程均可验证。

### Sync

- 安全评审与密钥恢复演练通过。
- 服务端无法读取标签明文。
- 离线编辑和双设备冲突具备确定性测试。
- 用户可删除账户及服务器数据。

## 12. 风险与应对

| 风险 | 影响 | 应对 |
|---|---|---|
| 误关或恢复不完整 | 直接失去信任 | 操作日志、预览、撤销、恢复报告、回收站 |
| Chrome API 限制特殊 URL | 部分标签无法恢复 | 捕获时标记能力，恢复前提示 |
| 快照过多导致本地存储膨胀 | 性能和配额问题 | 去重、增量快照、保留策略、容量面板 |
| 付费墙引发反感 | 差评和流失 | 安全能力免费、已有数据可读可导出 |
| 同步破坏“100% 本地”定位 | 品牌信任受损 | 默认关闭、端到端加密、清晰分层表达 |
| 功能过多使新标签页复杂 | 激活下降 | 默认“现在”视图，渐进展示高级能力 |

## 13. 待验证假设

在开发 Sync 或 Team 前，至少验证：

1. 用户是否将“自动快照与恢复”列为前三价值点。
2. 用户更偏好 US$19–29 买断，还是包含持续备份的订阅。
3. 免费 3 个快照是否足以体验价值但仍能产生升级动机。
4. 工作空间是高频主入口，还是域名仪表盘仍是主入口。
5. 用户是否接受可选账户，以及对自托管同步的需求比例。

建议通过 10–15 名目标用户访谈、商店 beta 和匿名漏斗完成验证。
