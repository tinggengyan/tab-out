# Tab Out 域名聚合交互演示检查

日期：2026-11-11。

结果：桌面主要动线验证通过；这是 HTML 提案，不是正式扩展实现。

## 本次修正

用户指出前版丢失了按域名聚合及重复检测。本版恢复域名卡片网格，跨窗口归组，显示来源窗口、重复份数，提供全局及单域名重复清理。保留明确的选择模式及已保存原地展开。前版窗口列表不再作为推荐方案。

重复以完整 URL 相同判定；不会合并仅主题类似的页面或忽略查询参数。自动清理优先保留固定标签，其次保留正在浏览的副本；固定标签不会被批量去重关闭。保存时同一 URL 仅存一条链接。

## 实际点击验证

1. 初始 9 个标签、7 个域名、2 个窗口；同网址的两个跨窗口副本显示在同一域名卡片，发现 2 个多余副本。
2. 全局清理使打开计数 9→7，保存组数仍为 3；撤销恢复到 9。单域名清理 Anthropic 后仅剩另一组的 1 个多余副本。
3. 选择模式点击两个不同域名的网页标题，显示已选 2 页；打开计数仍为 9，无正在浏览状态。
4. 收起少数派域名的 2 个重复标签：保存 1 个网页、关闭 2 个标签；打开计数 9→7、保存组数 3→4。撤销恢复 9 和 3。
5. 再次收起并查看：保存记录展开后仅 1 条链接。打开使计数 7→8；再次打开仍为 8，复用现有网页，保存记录仍保留。
6. 浏览器控制台未观察到 error/warn；已重置演示并将预览标签标记为交付产物。

提取内嵌 JS 后 Node 语法检查通过。与本次修改前的 SHA256 清单比对，extension/ 非元数据文件未变；仅系统生成的 .DS_Store 有差异。本演示仅操作内存中的示例，不连接 Chrome 扩展 API、不持久化真实标签。
