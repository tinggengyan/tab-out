# Tab Out 统一搜索与平台别名设计

日期：2026-09-14

状态：对话中的产品规则已获用户同意；本文供实施前复核。

## 目标与依据

用户最频繁的问题是找不到已打开页面、反复切换与重复打开页面；其次是记不住参数化搜索入口的 alias。首版提供一个无需记住缩写的入口：未指定平台时搜索已打开标签，指定平台时直接执行该平台的搜索。

Chrome 的 `@tabs` 和 Raycast 已提供部分能力，但不了解或不使用这些工具的用户仍是目标人群。Tab Out 的基础功能应易发现、免费可用，不以功能独占性作为开发前提。长期业务目标是订阅收入；团队共享、跨设备与项目上下文尚属后续待验证方向。

## 首版范围

- 修复默认 Free 用户的 `to` 标签搜索与切换链路。
- 新标签页提供可见的统一搜索入口；Chrome 地址栏通过 `to` 进入扩展搜索模式。
- 平台配置包含显示名称、多个别名、平台域名及搜索 URL 模板。
- 本地保存配置，支持平台配置导入导出，并纳入完整备份。
- 展示重复标签数量及可选择的现有标签；本次不增加自动关闭行为。

不包含：Raycast 集成、侧栏、云同步、团队共享、内部文档抓取、AI 归类，以及将现有工作空间搜索等付费能力全部解锁。

## 已确认的交互规则

| 输入 | 默认行为 |
|---|---|
| `支付接入` | 搜索已打开标签，不自动发起外部搜索 |
| `语雀 支付接入` | 通过语雀 URL 模板搜索“支付接入” |
| `yuque 支付接入` | 与上例相同 |
| `yq 支付接入` | 与上例相同 |
| `语雀` | 展示平台入口，提示继续输入关键词，不跳转空搜索 |
| 部分平台名称 | 显示匹配的平台建议；显式选择建议可补全平台前缀 |

用户无需先选择知识库。默认语雀入口直接搜索，知识库范围由用户进入网站后调整。用户仍可自行配置指定知识库的独立入口。

匹配平台名称或别名后的空白是命令边界，不能把 `yqdocs` 当作 `yq`。实现细则采用首尾去空白、Unicode NFKC 及大小写归一化比较；多个名称可能形成前缀时，取最长的完整匹配项。查询内容保留大小写与内部空白，只去除首尾空白。

明确的平台命令按 Enter 执行新搜索；不因为已有同网址标签而擅自改为切换。显式选择标签建议则跨窗口切换至该标签。没有匹配平台的普通文本不当作任意网址执行，也不静默转交 Google。

地址栏未选择建议直接提交普通查询时，打开 Tab Out 搜索界面并带入查询，避免当前的无反馈返回。平台命令可直接执行，两个入口共享解析规则。

## 配置与校验

单个平台记录：`id`、`name`、`aliases`、`domain`、`searchUrlTemplate`。ID 使用 `crypto.randomUUID()`。显示名称也参与命令识别；别名可为空，不能强迫用户填写或记忆缩写。

模板使用一个字面量 `{Query}`，替换值用 `encodeURIComponent()` 编码，防止中文、空格、`&`、`#` 破坏查询。模板必须是无用户名密码的 HTTP(S) URL；占位符只允许在路径或查询部分，不能位于协议、主机或 fragment。平台域名用于识别和展示，搜索模板可以使用另一搜索主机，保存界面须清楚显示实际目标主机。

采用以下实现边界：最多 100 个平台、每个平台 20 个别名，名称或单个别名不超过 80 字符，域名不超过 253 字符，模板不超过 4096 字符。拒绝空名称、控制字符、非法模板及跨平台的名称／别名冲突；同平台归一化重复项合并。错误需定位到具体字段，保存失败不改变旧配置。

不预置未经验证的语雀搜索 URL，也不收集 API Token 或网站登录凭据。允许用户复制真实搜索网址并替换关键词为 `{Query}`；配置页提供测试按钮，只有用户点击后才打开测试搜索。

## 结果与错误状态

已打开标签结果显示标题、域名、窗口标识和明确的“切换”动作；平台结果显示名称、目标主机与“搜索”动作。重复统计仅按精确 URL 计算，查询参数、片段或不同路径不擅自合并。不能只按域名判断同一个页面。

无结果时展示空状态及平台提示。标签在选择前被关闭时提示结果已失效并刷新，不自动重开。窗口聚焦、打开链接或存储失败时显示可理解的错误；禁止静默吞掉失败。快速连续输入只展示最新查询结果，避免旧异步请求覆盖新结果。

## 代码组织与数据兼容

沿用原生 JavaScript、`TabOutCore` 模块方式及 `chrome.storage.local`，不新增运行时 npm 依赖或网页读取权限。

- 新增平台搜索解析／验证模块，负责别名匹配和 URL 生成，供页面和后台共享。
- 新增平台配置 repository，使用独立存储键 `searchPlatformsV1`；旧快捷入口 `shortcuts` 保持兼容，不擅自转换成搜索模板。
- `extension/background.js`：将打开标签的基础搜索与高级资产搜索权限分离；使用明确的结果身份处理切换，避免同 URL 多标签时选错窗口；接入平台命令。
- `extension/app.js`、`extension/index.html`、`extension/style.css`：接入可见搜索入口、结果及配置面板；新解析逻辑不继续堆入 `app.js`。
- `extension/i18n.js`：同步中英文提示、错误和无障碍名称。
- schema、迁移与 backup service：平台键缺失时视为空数组；旧备份保持可导入，新完整备份包含平台配置并校验。

独立平台导入采用合并方式，预览新增及冲突项；冲突项不自动覆盖，用户取消则不写入。全部预览确认后一次写入有效合并结果。完整备份继续沿用现有的确认与恢复语义，不静默丢弃配置。

平台配置和查询默认留在设备上；只有显式执行搜索才向目标网站发送查询。日志不得记录查询、内部 URL 或平台名称。

## 验收与验证

1. 默认 Free、无需购买，两个入口均能查询打开标签并跨窗口切换；其他高级能力门槛不被绕过。
2. `语雀`、`yuque`、`yq` 在同配置下生成同一目标；未知前缀作为普通标签查询。
3. 中文、空格及 `&`、`#` 正确编码；非法协议、模板和别名冲突被拒绝。
4. 输入平台命令可直接回车，不出现必选知识库步骤；只有平台名称时提示输入关键词。
5. 同 URL 多标签显示重复数量，并切到用户选定的具体标签；平台搜索允许明确的新搜索行为。
6. 配置新增、编辑、删除、刷新后读取、导入冲突、旧备份与完整备份往返均有测试。
7. 快速输入、过期标签、Chrome API 和存储失败、中英文与键盘操作有可重复验证。

以 Node 内置 runner 测试解析器、repository、备份和 Chrome adapter 行为；在隔离 Chrome profile 验证真实 omnibox 注册与选择结果，不用用户工作标签做破坏性测试。运行 `npm test`、`npm run check`、`npm run package`；浏览器验证遵循现有 `tools/chrome-e2e.mjs` 流程。测试通过后再更新 README、实现状态与变更日志，不能把规划写为已经可用。

## 后续商业验证

观察找到目标所需时间、搜索后成功切换比例、每周重复使用，以及重复打开是否减少。基础搜索承担获客与留存；项目关联、共享平台配置和跨设备延续需独立验证付费需求，本次不承诺其实现或订阅价格。
